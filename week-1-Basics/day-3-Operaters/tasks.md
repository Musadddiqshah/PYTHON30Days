  DAY 3 — TASKS (Operators)

Instructions:
- Write answers in a file called tasks.py
- Try first, then run and check.
- Use easy names like a, b, x, num1, num2.


Q1. Arithmetic
Create a = 20 and b = 6.
Print: sum, difference, product, division,
       floor division, modulo, power.


Q2. Predict the output
Write the answers in a comment BEFORE running:

    print(7 // 2)
    print(7 % 2)
    print(2 ** 3)
    print(10 / 4)


Q3. Comparison
Create x = 15 and y = 25.
Print: x == y, x != y, x > y, x < y, x >= y, x <= y
Each answer must be True or False.


Q4. Assignment operators
Start with n = 5.
Use these in order and print n after each step:
    n += 3
    n *= 2
    n -= 4
    n //= 2
Write expected value in a comment.


Q5. Logical operators
Create is_raining = True and have_umbrella = False.
Print:
    is_raining and have_umbrella
    is_raining or have_umbrella
    not is_raining
Write one sentence in a comment explaining each result.


Q6. Membership
Create word = "python".
Print:
    "p" in word
    "P" in word
    "th" in word
    "z" not in word
Then comment: why is "P" in word different from "p" in word?


Q7. Identity — careful!
Create a = 100 and b = 100.
Print: a == b, a is b

Then create c = 1000 and d = 1000.
Print: c == d, c is d

Comment: which one (== or is) is the correct way
to compare values, and why?
